## What it does

`main.py` writes one funny line of text to `/output/entry.txt`:

> My agent read AGENTS.md, deleted the database, restored it from backup, then billed me for the lesson.

The program is fully deterministic: it writes the same fixed line on
every run, with no randomness, no network access, and no clock or
environment reads.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
